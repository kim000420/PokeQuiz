1단계: 서버 구축 및 기본 통신 연결

목표: 
MySQL DB와 연동하여 포켓몬 퀴즈 게임을 만들기 위한 서버 아키텍처 설계.

초기 구상:
처음에는 Unity에서 MySQL 직접 연결을 고려했으나, **보안 문제(DB 정보 노출)**로 인해 **중계 서버(API 서버)**를 두는 방식으로 결정했습니다.
서버 기술로 **.NET 8.0 (C#)**을 선택하고, Google Cloud VM (Ubuntu 22.04) 환경을 사용하기로 확정했습니다.

작업:
VM에 .NET 8.0 SDK 설치 확인.
dotnet new webapi 템플릿으로 PokemonApi 프로젝트 생성 (초기에는 console로 잘못 생성했다가 다시 생성).
필수 라이브러리 설치: Microsoft.EntityFrameworkCore, Pomelo.EntityFrameworkCore.MySql, CsvHelper.



2단계: MySQL DB 설정 및 연결

목표: 
.NET 서버가 MySQL DB에 접속할 수 있도록 설정.

작업:
appsettings.Development.json 파일에 ConnectionStrings 추가.
VM에 mysql-server 설치 및 mysql_secure_installation 보안 설정 진행.

발생한 문제점: 
MySQL Workbench 접속 실패 (Timed out, Authentication Failed).

문제 해결 과정:
1. SSH 터널링 시도: 3306 포트를 직접 여는 것은 위험하므로, Standard TCP/IP over SSH 방식을 시도함.
2. 접속 정보 수정: SSH Username을 tmdlsghk...에서 root로, 다시 rsa-key...로 바꾸며 테스트함.
3. 키 파일 변환: PuTTYgen으로 만든 .ppk 키가 문제인가 싶어서 OpenSSH 키로 변환을 시도했으나, 결국 워크벤치 버전에 맞는 설정을 찾아냄.
4. MySQL 내부 보안 설정: root 계정이 비밀번호 접속이 안 되는 auth_socket 방식임을 발견하고, caching_sha2_password 방식으로 변경 및 비밀번호 설정(ALTER USER...).

방화벽 점검
- GCP 방화벽은 열려있음을 확인.
- PuTTY는 접속되는데 워크벤치만 안 되는 현상 발견.
- 윈도우 방화벽이 mysqlworkbench.exe를 차단하는 것으로 강력히 의심되어 예외 처리를 시도했으나 실패.

결과: MySQL Workbench 접속 성공 및 pokemon_db 데이터베이스 생성 완료.



3단계: 데이터 모델링 및 CSV 임포트 (DB 시딩)

목표: PokemonDB_v007.CSV 파일을 읽어 DB 테이블을 자동 생성하고 데이터를 넣기.

작업:
Pokemon.cs (모델), PokemonDbContext.cs (DB 컨텍스트), DataSeeder.cs (임포터) 작성.
Program.cs에서 서버 시작 시 DataSeeder가 자동 실행되도록 설정.

발생한 문제점
1. Address already in use (5065 포트 사용 중).
해결: ss -lntp로 좀비 프로세스 PID 확인 후 kill -9로 강제 종료.

2. DexId 중복 키 오류 (System.InvalidOperationException).
해결: Pokemon.cs에 Id (Auto Increment)를 기본 키로 추가하고, DexId는 일반 컬럼으로 변경.

3. CsvHelper가 Id 헤더를 못 찾음.
해결: Pokemon.cs의 Id 속성에 [Ignore] 태그 추가.

4. DB 테이블 구조 불일치 (Unknown column 'Id').
해결: MySQL Workbench에서 DROP TABLE Pokemons; 실행 후 서버 재시작하여 새 구조로 테이블 재생성.

결과: 1203개의 포켓몬 데이터 DB 임포트 성공 (DB 시딩 완료!).



4단계: Unity와 서버의 통신 (HTTP -> TCP 전환)
초기 시도 (HTTP API):
QuizController.cs를 만들어 .../api/quiz/random 엔드포인트 생성.
curl (VM 내부, Windows cmd) 테스트 성공.

문제 발생: Unity(UnityWebRequest)에서만 Cannot connect to destination host 문제 발생.
원인 분석:
서버가 localhost로만 열려있음 -> dotnet run --urls "http://0.0.0.0:5065"로 해결.
Windows 방화벽이 Unity.exe의 5065 포트 통신을 차단함 -> 방화벽 예외 추가.

최종 해결: 
UnityWebRequest 대신 C# 표준 라이브러리인 **HttpClient**를 사용하여 PC 보안 정책을 우회하고 통신 성공 ([HttpClient 성공]).

설계 변경 (TCP 통합):
간단한 게임 경험을 위해 HTTP API 방식을 버리고, 기존 채팅 서버(ProgramTCPServer.cs)에 DB 기능을 통합하기로 결정.
이유: 실시간 채팅과 퀴즈 로직을 하나의 TCP 소켓 연결로 처리하는 것이 더 효율적임.

결과: PokemonChatServer라는 새로운 통합 프로젝트 생성.



5단계: 통합 서버 (TCP + DB) 구축
목표: 복잡한 API 방식을 버리고, 기존 채팅 서버(ProgramTCPServer.cs)에 DB 접속 기능을 통합하여 구조 단순화.

작업:
PokemonChatServer 새 프로젝트 생성 및 MySqlConnector 설치.
Program.cs 재작성: TcpListener (채팅) + MySqlConnection (DB 쿼리) + Timer (힌트) 로직 통합.

문제1: CS1503 (Argument 1: cannot convert from 'string' to 'int').
원인: reader.IsDBNull("ColumnName") 메서드는 문자열 컬럼명을 지원하지 않음.
해결: IsDBNull을 제거하고 string? 타입과 삼항 연산자로 NULL 처리 로직 변경.

문제2: CS0246 (MySqlConnector not found).
해결: dotnet add package MySqlConnector 및 dotnet restore로 종속성 복구.

채팅 메시지와 힌트 텍스트 등장 시 DOTween(Ease.OutBack)을 적용하여 생동감 추가.

14단계: 모바일 채팅창 UX 개선
목표: 모바일 환경에 맞는 UI 크기및 앵커 수정

작업: 
배경 UI 수정
UI크기 세로모드 모바일 환경에 맞게 수정(앵커,크기)
모바일 환경에 맞게 폰트 사이즈 늘리기
채팅 입력 시 키패드에 가려지지 않도록 채팅창 축소/확대 기능 구현.

문제1: 채팅바 버튼을 눌러 입력후 전송 버튼을 누르면 채팅창이 확대되는 현상 발생
해결: SendButtonTrigger.cs(OnPointerDown)를 추가하여, 전송 버튼을 누르는 순간 확대 로직을 차단(BlockNextExpand)하여 해결.
문제2: 채팅입력을 마치고 채팅창 확대시 채팅장이 최상단으로 이동하는 현상 발생
해결: 채팅이 아래에서부터 쌓이도록 Content의 Pivot과 Alignment를 하단 기준으로 변경.



15단계: 안드로이드 빌드 및 환경 설정
문제1: 빌드 시 "Unsupported Input Handling" 경고 발생.
Active Input Handling을 Input Manager (Old)로 변경.
해결: "JDK not found" 오류 발생 → 유니티 허브/Preference에서 JDK 경로 재설정 완료.

문제2: Nox(앱플레이어)에서 실행 시 검은 화면 발생.
에뮬레이터(x86)와 앱(ARM64) 간의 아키텍처 불일치 및 Vulkan 그래픽 API 호환성 문제.
해결: Vulkan 제거 및 x86-64 아키텍처 추가 (또는 Mono 빌드 시도).



16단계: 크래시 해결 및 입력 시스템 최종 전환
문제1: 검은 화면은 해결됐으나, 앱 실행 후 기능이 먹통(터치 불가) 되는 현상 발생.
과정: SIGSEGV (Signal 11) 크래시 및 Input System 관련 충돌 확인.
원인: 프로젝트 설정은 Old인데, 씬의 EventSystem에는 New Input Module이 붙어있어 터치 입력이 차단됨.
해결: Unity 6 표준인 New Input System으로 완전히 전환
Project Settings → Input System Package (New)로 변경.
ChatUI.cs 코드 수정 (Input.GetKey 제거 → Keyboard.current 사용).
EventSystem 컴포넌트 교체 (Input System UI Input Module).
